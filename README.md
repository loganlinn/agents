# agents

Personal collection of agent prompt templates and related stuff.

## Layout

```
templates/<category>/<name>.md
```

Each file is a reusable prompt template. Customize the bracketed sections
`[like this]` to fit specific needs.

## Sources

- Prompt templates under `templates/` adapted from the
  [Devin Docs — Prompt Templates Cheat Sheet](https://docs.devin.ai/essential-guidelines/prompt-templates-cheat-sheet).
